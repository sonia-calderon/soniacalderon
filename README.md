# Sonia Calderón | Portfolio

Personal portfolio site. The site includes a hero, about section, experience, skills, selected projects, and contact links.

## Technologies

- React
- TypeScript
- Vite

## Installation

```bash
git clone https://github.com/sonia-calderon/soniacalderon.git

cd soniacalderon

pnpm install

pnpm dev
```
